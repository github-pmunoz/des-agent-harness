Hand a self-contained piece of deep work to a subagent and get back only its findings: an investigation of the code that reports paths, lines, names and values; a rewrite or a set of edits; a test loop until green. The subagent runs in its own context with Read, Write, Edit and Bash and none of your conversation, so the task must stand on its own. Do not use it to read a file for you — you have Read — or to verify a result: put the verification in `check`. A brief carries instructions and line anchors, never the content of a file or a document.
